# Marcelo Araújo Fight

Site institucional da academia Marcelo Araújo Fight, com foco em apresentar a marca, modalidades, professores, vídeos de treino, horários e formas de contato.

## O Que Foi Usado

- Next.js com App Router
- React
- TypeScript
- Tailwind CSS
- Imagens otimizadas em `public/media`
- Vídeos locais em MP4
- Componentes separados por seções e interações

## Estrutura Geral

- `src/app`: estrutura principal da aplicação
- `src/components`: componentes de layout, seções e interações
- `src/content`: textos, links, contatos e caminhos de mídia usados pelo site
- `public/media`: logos, fotos, vídeos e imagens da Hero Section
